# Location data attribution

India state and city data in `india-states-cities.json` is extracted from:

**[countries-states-cities-database](https://github.com/dr5hn/countries-states-cities-database)**  
Release: `v3.2-export.7`  
License: [Open Database License (ODbL) v1.0](https://github.com/dr5hn/countries-states-cities-database/blob/master/LICENSE)

Only the India (`IN`) subset is bundled. Regenerate with:

```bash
node scripts/extract-india-locations.mjs
```
